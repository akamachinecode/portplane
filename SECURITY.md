# Security policy

Portplane starts and stops processes, reads process information and connects to other machines over SSH. Please report vulnerabilities **privately** through GitHub: *Security → Report a vulnerability* on this repository. Do not open public issues for security problems.

We aim to acknowledge reports within 72 hours and to publish a fix and an advisory as soon as possible. Supported versions: the latest minor release. Before v1.0, only the latest release is supported.
